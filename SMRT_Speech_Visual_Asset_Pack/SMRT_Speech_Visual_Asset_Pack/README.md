# SMRT Speech visual asset pack

Warm clinical premium design, plum and coral, hybrid icons, light and dark app themes.

**Start here:** `integration/CLAUDE_CODE_INTEGRATION_PROMPT.md`.

The pack contains individual **SVG, PNG and JPEG** icon variants, module artwork, 15 activity icons, navigation/actions/feedback icons, borders, backgrounds, app icons, CSS design tokens, JSON token map and asset manifest.

SVGs are preferred for icons; PNGs preserve transparency; JPEGs use a warm cream background and should not be used as transparent overlays. Background JPEGs are decorative app-shell assets only. The reference poster is a concept preview, not a complete screen specification.

**Not included:** 700 vocabulary stimulus photographs, authored vocabulary, reading stimulus photographs, running app code, or tested integration.

**Clinical design:** retain 60-point targets, 20px body type, accessible contrast, calm light therapy canvas, and no forced animation.
